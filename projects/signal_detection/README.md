# 信号检测与估计

**阶段：** 第一阶段  
**对应章节：** 第 1 章 DSP基础、第 2 章优化与机器学习  
**状态：** 可运行版本；已加入非平稳信号、时频检测与可选轻量 CNN

## 项目目标

从含噪观测中判断目标信号是否存在，并估计信号的关键参数。项目用于建立后续视觉检测、音频识别和模型评估的共同基线：

```text
信号表示 → 特征/滤波 → 检测或估计 → 阈值与错误权衡
```

第 1 章关注观测、频谱和检测统计量；第 2 章则用本项目说明另一种优化问题：在给定虚警预算 $\alpha$ 下，选择阈值 $\tau$，使检测率尽可能高。它不是替代 LMS/Adam 的训练实验，而是把“变量—目标—约束—评估”的优化思维带回一个可解释的检测任务。

## 第一版范围

先使用合成信号，不依赖 GPU、API 或外部数据集：

- 生成包含多个频率成分和噪声的信号；
- 比较时域、频域和时频表示；
- 比较能量检测、匹配滤波或频谱峰值检测；
- 调整噪声强度和检测阈值；
- 绘制检测率、虚警率或 ROC 曲线；
- 记录至少一个失败案例。

在此基础上，第二版加入线性调频（chirp）非平稳信号：比较忽略时间变化的全局 FFT 峰值与沿预期时频轨迹累积能量的检测器，并用错误轨迹展示时频先验失配。

可选的第三组实验使用 1,249 参数的轻量 1D CNN，在独立训练集上学习检测特征，用验证集校准虚警阈值，再在测试集上与传统检测器比较。它需要 PyTorch，但不影响默认项目入口。

## 第一版结论应如何阅读

能量检测只利用“整体能量增加”这一弱先验；匹配滤波还利用了已知波形的频率和相位，因此在模板正确时通常更灵敏。右图的模板失配则说明：更强的先验也会带来更明确的适用边界。这正是后续学习中“表示、模型假设与泛化能力”之间权衡的早期例子。

对于频率随时间变化的 chirp，全局 FFT 会把能量摊到多个频率上；时频轨迹检测保留“什么频率在什么时刻出现”的结构，因此在同一虚警预算下更灵敏。但如果预设轨迹错误，优势会明显下降。它把第 1.4 节的时频表示和第 1.6 节的检测问题连接成一个可测量的项目结论。

默认 CNN 实验中，模型保留粗粒度时间结构，因此能从数据中学到 chirp 模式；但它仍低于使用正确轨迹先验的检测器。这不是模型排行榜，而是一个重要对照：手工方法用明确先验换取数据效率和可解释性，学习方法用训练数据换取特征适应能力。扩大信号变化范围后，应重新检查两者在分布偏移下的表现。
