# 学习路径

路径只决定从哪里开始，不规定完成时间。选择依据是已有知识和学习目标。

## 快速通道

适合已经理解反向传播、CNN 和基本序列模型，希望直接学习 LLM 的读者。

```text
第4章 Transformer → 第5章 LLM → 第6章应用 → 第7章多模态 → 第8章工程
```

第 1—3 章可以作为概念缺口的回查入口。例如，不熟悉卷积时回到第 1、3 章，不熟悉梯度训练时回到第 2 章。

## 完整路径

适合希望理解“信号处理方法如何逐步变成可学习模型”的读者。

```text
第1章 DSP → 第2章优化与机器学习 → 第3章深度学习
      → 第4章 Transformer → 第5章 LLM → 第6—8章应用与工程
```

正文优先建立概念和实验联系。数学推导、训练细节和专题内容放在各章 `extensions/`，需要时再读。

## 按目标选择

| 当前情况 | 建议入口 | 原因 |
|----------|----------|------|
| 熟悉深度学习，只想理解 LLM | 第4章 | 直接补齐注意力、位置和生成机制 |
| 会编程，但机器学习基础不完整 | 第2章 | 先理解目标函数、训练和基本模型 |
| 有信号、通信或控制背景 | 第1章 | 利用已有的变换、滤波和估计知识建立连接 |
| 准备做多模态项目 | 第3章后进入第7章 | 先用视觉理解对齐主干，再推广到音频和传感器信号 |
| 准备部署 LLM 应用 | 第6章后进入第8章 | 先明确应用瓶颈，再讨论成本和可靠性 |

“深度学习”不是第三条独立路径。任何路径都可以在某个问题上进入扩展文章、论文或项目，然后回到主线。

## 每章怎么学

1. 先读章节主图和核心问题，确认本章处理的信息与目标。
2. 阅读正文并运行对应代码，不要求一次读完所有扩展内容。
3. 完成最低实践：修改参数、保存结果、解释变化。
4. 无法解释结果时，再回查前置章节或数学附录。

完成标准见[全书概览](03_overview.md#完成一章的判断标准)，运行方式见[代码运行指南](../appendix/C_code_guide.md)，综合实践见[项目说明](../../projects/README.md)。
