# 1.6 信号检测

**核心问题：** 如何判断信号是否存在？如何在噪声中检测信号？

---

## 检测问题的数学框架

### 问题设置

**观测模型：**
$$y[n] = \begin{cases} w[n] & \text{假设 } H_0 \text{（无信号）} \\ s[n] + w[n] & \text{假设 } H_1 \text{（有信号）} \end{cases}$$

其中：
- $y[n]$：观测信号
- $s[n]$：待检测的信号
- $w[n]$：加性高斯白噪声（AWGN）

### 检测器的任务

**给定观测 $y[n]$，判断：**
- $H_0$：信号不存在（零假设）
- $H_1$：信号存在（备择假设）

**决策规则：**
$$\text{如果 } T(y) > \gamma \text{，则判定 } H_1 \text{；否则判定 } H_0$$

其中 $T(y)$ 是检验统计量，$\gamma$ 是判决阈值。

---

## 假设检验理论

### 两类错误

**第一类错误（假警报，False Alarm）：**
$$P_{fa} = P(\text{判定 } H_1 | H_0 \text{ 真实})$$

含义：信号不存在，但错误地判定为存在。

**第二类错误（漏检，Miss Detection）：**
$$P_{md} = P(\text{判定 } H_0 | H_1 \text{ 真实})$$

含义：信号存在，但错误地判定为不存在。

**检测概率：**
$$P_d = 1 - P_{md} = P(\text{判定 } H_1 | H_1 \text{ 真实})$$

含义：正确检测到信号的概率。

### 权衡关系

**关键观察：** 降低虚警率 $P_{fa}$ 与提高检测率 $P_d$ 通常存在阈值权衡；设计目标不是让二者都小。

- 降低阈值 $\gamma$ → $P_d$ 增加，$P_{fa}$ 也增加
- 提高阈值 $\gamma$ → $P_{fa}$ 减少，$P_d$ 也减少

**设计目标：** 在给定 $P_{fa}$ 的约束下，最大化 $P_d$。

---

## 似然比检验（Likelihood Ratio Test, LRT）

### 最优检验

**Neyman–Pearson 引理：** 对两个完全指定的简单假设，在虚警概率不超过给定水平的检验中，似然比检验具有最大检测概率。复合假设或未知参数还需要额外处理。

$$\Lambda(y) = \frac{p(y|H_1)}{p(y|H_0)} \stackrel{H_1}{\gtrless} \gamma$$

其中 $p(y|H_i)$ 是在假设 $H_i$ 下的似然函数。

### 高斯信号的LRT

**假设：**
- 信号 $s[n]$ 已知
- 噪声是AWGN，方差为 $\sigma^2$

**似然函数：**
$$p(y|H_0) = \prod_{n} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{y[n]^2}{2\sigma^2}\right)$$

$$p(y|H_1) = \prod_{n} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y[n]-s[n])^2}{2\sigma^2}\right)$$

**对数似然比：**
$$\ln \Lambda(y) = \sum_{n} \frac{2y[n]s[n] - s[n]^2}{2\sigma^2}$$

**简化后的检验统计量：**
$$T(y) = \sum_{n} y[n] s[n] \stackrel{H_1}{\gtrless} \gamma$$

**直观理解：** 检验统计量是观测信号与已知信号的相关性。

---

## 接收机工作特性（Receiver Operating Characteristic, ROC）

### ROC曲线

**定义：** 在不同阈值下，$P_d$ 与 $P_{fa}$ 的关系曲线。

**绘制方法：**
1. 改变阈值 $\gamma$
2. 对每个 $\gamma$，计算 $P_d$ 和 $P_{fa}$
3. 绘制 $(P_{fa}, P_d)$ 曲线

### ROC曲线的性质

**完美检测器：**
- 曲线经过点 $(0, 1)$
- 可以同时实现 $P_{fa} = 0$ 和 $P_d = 1$

**随机检测器：**
- 曲线是对角线 $P_d = P_{fa}$
- 检测性能等同于随机猜测

**有效检测器：**
- 合理选择分数方向后，ROC 通常位于对角线上方；若位于下方，可以检查分数方向是否反了
- 在同一任务、数据分布和正负类定义下，曲线越接近左上角通常越好

### 曲线下面积（AUC）

**定义：** ROC曲线下的面积。

$$\text{AUC} = \int_0^1 P_d(P_{fa}) dP_{fa}$$

**性质：**
- AUC = 1：完美检测器
- AUC = 0.5：随机检测器
- 在同一任务与数据分布下，AUC 越大表示随机正样本得分高于随机负样本的概率越大；它不编码具体工作点的错误代价

## 常见检测器

### 1. 能量检测器（Energy Detector）

**适用场景：** 信号未知，只知道噪声功率。

**检验统计量：**
$$T(y) = \sum_{n=0}^{N-1} |y[n]|^2$$

**决策规则：**
$$T(y) \stackrel{H_1}{\gtrless} \gamma$$

**优点：**
- 简单，计算快
- 不需要知道信号形式

**缺点：**
- 当信号波形已知且模型匹配时，通常不如利用相位与波形信息的相关检测器
- 对噪声功率估计敏感

### 2. 相关检测器（Correlation Detector）

**适用场景：** 信号已知。

**检验统计量：**
$$T(\mathbf y)=\operatorname{Re}\left\{\sum_{n=0}^{N-1}y[n]s^*[n]\right\}$$

**决策规则：**
$$T(y) \stackrel{H_1}{\gtrless} \gamma$$

**优点：**
- 在给定虚警率、已知信号和高斯噪声等假设下具有 Neyman-Pearson 最优性
- 对已知信号有较高的检测概率

**缺点：**
- 需要精确知道信号

### 3. 匹配滤波器（Matched Filter）

**思想：** 用与信号相匹配的滤波器。这是卷积在检测中的直接应用。

**冲激响应：**
$$h[n] = s^*[N-1-n]$$

其中 $s[n]$ 是待检测的信号，$N$ 是信号长度。

**输出（卷积运算）：**
$$
y_{\text{out}}[n]
=\sum_m y[m]h[n-m]
=\sum_m y[m]s^*[N-1-n+m].
$$

**在 $n = N-1$ 时的输出：**
$$y_{\text{out}}[N-1]=\sum_{m=0}^{N-1}y[m]s^*[m]$$

这正好得到相关检测器所使用的复内积。

**与相关检测器的关系：**
- **相关检测器**：直接计算复内积，并根据假设取实部、幅度或幅度平方
- **匹配滤波器**：通过卷积得到复内积；在上述取实部的检验中，$T(\mathbf y)=\operatorname{Re}\{y_{\text{out}}[N-1]\}$
- **本质**：两者都是卷积运算，只是实现方式不同

**优点：**
- 在已知信号和高斯噪声等条件下最大化输出信噪比（SNR）
- 可实现相关检测器对应的检验统计量
- 实现灵活 — 可用硬件或软件实现卷积
- 直观理解 — 滤波器与信号"匹配"程度越高，输出越大

**缺点：**
- 需要精确知道信号形式
- 单个已知对齐位置的内积为 $O(N)$；若要扫描大量时延，直接相关的总成本更高，可根据长度和硬件使用 FFT 加速

**应用场景：**
- 雷达系统：检测已知脉冲信号
- 通信系统：检测已知调制信号
- 声纳系统：检测已知声纳信号
- 医学诊断：检测已知的生物信号模式

## 检测性能分析

### 信噪比（Signal-to-Noise Ratio, SNR）

**定义：** SNR 必须结合观测区间和归一化方式说明。对上面的长度有限、已知确定性实信号，常用匹配滤波输出 SNR 为

$$
\operatorname{SNR}_{\mathrm{out}}
=\frac{E_s}{\sigma^2}
=\frac{\sum_n s[n]^2}{\sigma^2},
$$

其中 $E_s$ 是该观测区间内的信号能量，$\sigma^2$ 是每个实采样点的噪声方差。这不是“平均信号功率除以平均噪声功率”的唯一通用定义。

**单位：** dB（分贝）
$$\operatorname{SNR}_{\mathrm{out,dB}} = 10 \log_{10}(\operatorname{SNR}_{\mathrm{out}})$$

### 检测性能与SNR的关系

**已知确定性实信号在 AWGN 下的检测性能：**

对于相关检测器，检验统计量 $T(y)$ 在两个假设下的分布为：

$$T(y) | H_0 \sim \mathcal{N}(0, \sigma^2 \|s\|^2)$$
$$T(y) | H_1 \sim \mathcal{N}(\|s\|^2, \sigma^2 \|s\|^2)$$

**检测概率：**
$$
P_d
=Q\left(Q^{-1}(P_{fa})-\sqrt{\operatorname{SNR}_{\mathrm{out}}}\right).
$$

其中 $Q(x) = \frac{1}{\sqrt{2\pi}} \int_x^{\infty} e^{-t^2/2} dt$ 是Q函数。

**关键观察：**
- SNR越高，$P_d$ 越高
- 要达到相同的 $P_d$，SNR越高越容易

## 典型场景

检测框架的形式相同，差别主要在于信号先验、阈值设置和误判代价。

### 1. 雷达系统

- 已知发射信号时，通常直接用相关检测器或匹配滤波器
- 通过 ROC 曲线选择阈值，在虚警率和漏检率之间做权衡
- 航空管制更怕虚警，防空场景更怕漏检

### 2. 通信系统

![Signal Detection](/assets/ch01_signal_detection.png)

**代码文件：** [`code/ch01_dsp/signal_detection.py`](../../code/ch01_dsp/signal_detection.py)  
**运行方式：** `python code/ch01_dsp/signal_detection.py`

- 用于判断接收端是否真正收到了有效信号
- 同步检测和导频检测本质上都是“在噪声里找已知模式”

### 3. 医学诊断

- ECG 常用来检测心律不齐
- EEG 常用来检测癫痫发作
- EMG 常用来检测肌肉异常

### 4. 地震学

- 用台站观测判断是否发生地震
- 结合多个传感器做震源定位
- 在早期波形上尽快触发预警

## 本节小结

信号检测是信号处理的重要应用：

- **数学框架**：假设检验、似然比检验
- **性能指标**：$P_d$、$P_{fa}$、ROC曲线
- **常见检测器**：能量检测器、相关检测器、匹配滤波器
  - 匹配滤波器是卷积在检测中的应用，在已知信号和高斯噪声等假设下具有最优性
- **性能分析**：SNR与检测性能的关系
  - 本质上是在“信号已知程度”和“噪声不确定性”之间做设计
- **典型场景**：雷达、通信、医学、地震学
