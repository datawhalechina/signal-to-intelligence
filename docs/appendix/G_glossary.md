# 附录 G：术语表

本术语表统一教程中跨 DSP、统计、深度学习、Transformer、LLM 和多模态使用的核心词汇。它回答“这个词在本教程中具体指什么”，数学符号和公式见[附录 A](A_math_reference.md)，章节数学前置关系见[附录 D](D_math_quick_reference.md)。

## 使用约定

- 中文正文优先使用“中文术语（英文，缩写）”作为首次定义，之后使用中文或公认缩写。
- 本教程统一使用“表示”，不把“表征”作为另一套概念；引用外部材料时可保留原词。
- `token` 在正文中保留英文。文本 token 可称“词元”，视觉 token 和信号 token 指模型序列单元，不一定对应自然语言词。
- 中文语境中的方案名称统一写作 Prompt、RAG、Agent；代码变量和英文句子遵循其自身大小写。
- 单独写“推理”容易混淆时，应明确使用“统计推断”“模型推理”或“推理能力”。
- 矩阵使用粗体大写，向量使用粗体小写；完整符号规范在附录 A 维护。

## G.3 深度学习与 Transformer

| 规范术语 | 英文 / 缩写 | 本教程中的含义 | 不要混同 | 首次重点章节 |
| --- | --- | --- | --- | --- |
| **张量** | Tensor | 带有一个或多个轴的数值数组 | 特定深度学习框架对象 | 第 3 章 |
| **批量** | Batch | 一次并行送入模型的一组训练样本或请求 | 完整数据集 | 第 3 章 |
| **通道** | Channel | 同一位置上的不同测量或特征维度 | 注意力头 | 第 1、3 章 |
| **token** | Token | 被模型作为一个序列位置处理的离散或连续单元 | 只等同于自然语言单词 | 第 4—5 章 |
| **分词** | Tokenization | 把文本转换为 token 序列及其 ID 的过程 | 嵌入查表 | 第 5 章 |
| **嵌入** | Embedding | 把离散对象或高维对象映射到连续向量空间的表示 | 所有中间表示 | 第 5 章 |
| **隐藏表示** | Hidden representation | 模型中间层产生、供后续层继续处理的表示 | 最终概率输出 | 第 3—5 章 |
| **logit** | Logit | softmax 或 sigmoid 之前的未归一化分数 | 概率 | 第 2、5 章 |
| **编码器** | Encoder | 把输入转换为上下文表示的模块 | 文本编码格式 | 第 3—4 章 |
| **解码器** | Decoder | 根据已有表示预测或生成输出的模块 | 文件解码器 | 第 3—5 章 |
| **注意力** | Attention | 根据查询与键的关系，对值进行数据依赖加权聚合的机制 | 可直接解释模型因果依据的证明 | 第 4 章 |
| **自注意力** | Self-attention | 查询、键和值来自同一序列的注意力 | 交叉注意力 | 第 4 章 |
| **交叉注意力** | Cross-attention | 查询与键值来自不同序列或模态的注意力 | 任意多模态融合 | 第 4、7 章 |
| **查询、键、值** | Query, Key, Value; Q/K/V | 注意力中定义检索需求、匹配依据和聚合内容的投影表示 | 数据库中固定字段 | 第 4 章 |
| **注意力掩码** | Attention mask | 限制哪些序列位置可以直接建立注意力连接的矩阵或规则 | 权重剪枝 | 第 4 章 |
| **因果掩码** | Causal mask | 禁止当前位置读取未来 token 的注意力掩码 | 通用稀疏注意力 | 第 4 章 |
| **位置编码** | Positional encoding | 向序列表示注入顺序或相对位置信息的方法 | token ID | 第 4 章 |
| **上下文窗口** | Context window | 单次模型计算能够接收的 token 范围 | DSP 的时间窗口 | 第 5 章 |
| **自回归** | Autoregressive | 把已知历史作为条件，逐步预测后续变量或 token | 必然使用 RNN | 第 3、5 章 |
| **模型推理** | Model inference | 固定参数后执行模型前向计算并得到输出的过程 | 统计推断、推理能力 | 第 5、8 章 |
| **KV cache** | Key-value cache | 自回归生成时缓存历史层的键和值，避免重复计算 | 通用结果缓存 | 第 4、8 章 |
| **Prefill** | Prefill | 处理完整输入上下文并建立初始 KV cache 的阶段 | 逐 token 解码 | 第 8 章 |
| **Decode** | Decode | 自回归生成中逐步产生新 token 的阶段 | tokenizer 的文本解码 | 第 8 章 |

## 容易混淆的四组概念

### 表示、特征、嵌入与 token

“表示”是上位概念；“特征”强调任务可用的变量；“嵌入”强调映射到连续向量空间；“token”强调序列中的处理单元。一个 token 会对应一个嵌入向量，但 token 本身不是向量。

### 预测、生成、模型推理与推理能力

预测给出目标变量或下一个 token 的分布；生成反复调用预测形成序列；模型推理是执行模型计算的阶段；推理能力描述模型解决多步问题的能力。四者不能互换。

### 表示对齐、偏好对齐与融合

表示对齐建立模态或来源之间的对应关系；偏好对齐调整模型行为与偏好或规范的关系；融合把多种信息组合起来。系统可以先对齐再融合，也可以在联合训练中同时学习，但评价指标不同。

### 信号检测与目标检测

信号检测通常判断目标信号或事件是否存在；计算机视觉目标检测还要输出类别和空间位置。二者共享阈值、误报、漏报和 ROC / PR 等思想，但输入、输出和匹配规则不同。

1. 在两个以上章节中使用，或在一个章节中存在明显歧义；
