# 5.0 信息论基础

**核心问题：** 什么是信息？如何衡量信息的不确定性？

---

## 为什么需要理解信息论

在 LLM 中：
- **交叉熵损失**是训练的核心目标函数
- **KL 散度**用于衡量两个概率分布的差异
- **互信息**用于理解特征之间的依赖关系
- **困惑度**用于评估模型性能

理解信息论可以帮助我们理解 LLM 的训练目标和评估指标。

---

## 信息熵

### 信息的定义

**信息量**衡量一个事件发生时带来的"惊讶程度"：

$$I(x) = -\log_2 P(x)$$

其中 $P(x)$ 是事件 $x$ 的概率。

**直观理解：**
- 概率高的事件（容易发生）：信息量小
- 概率低的事件（难以发生）：信息量大

**例子：**
- "明天太阳升起"：$P = 0.9999$，信息量 ≈ 0
- "明天下雨"：$P = 0.3$，信息量 ≈ 1.74 bits

### 熵（Entropy）

**定义：** 熵是信息量的期望值，衡量一个概率分布的**不确定性**：

$$H(X) = -\sum_x P(x) \log P(x)$$

对连续变量，对应量称为**微分熵**，通常记为小写 $h$：

$$h(X) = -\int p(x) \log p(x) dx$$

微分熵依赖坐标和单位，可以为负，不能直接套用离散熵的全部直觉。

**单位：**
- 以 2 为底：bits
- 以 $e$ 为底：nats
- 以 10 为底：hartleys（较少使用）

### 离散熵的性质

| 性质 | 说明 |
|------|------|
| 非负性 | 离散熵满足 $H(X) \geq 0$ |
| 最大值 | 对有限的 $N$ 个可能结果，均匀分布时最大，$H_{\max}=\log N$ |
| 最小值 | 当分布确定时为 0 |

### 例子

**均匀分布：** $P(x) = 1/N$ 对所有 $x$

$$H(X) = -\sum_{i=1}^{N} \frac{1}{N} \log \frac{1}{N} = \log N$$

**二元分布：** $P(x=1) = p$，$P(x=0) = 1-p$

$$H(X) = -p \log p - (1-p) \log(1-p)$$

最大值在 $p = 0.5$ 时达到，$H_{\max} = 1$ bit。

## 条件熵和联合熵

### 条件熵

**定义：** 给定 $Y$ 的条件下，$X$ 的熵：

$$H(X|Y) = -\sum_y P(y) \sum_x P(x|y) \log P(x|y)$$

**直观理解：** 如果我们已经知道 $Y$，$X$ 还剩多少不确定性。

### 联合熵

**定义：** 两个随机变量的联合分布的熵：

$$H(X, Y) = -\sum_x \sum_y P(x, y) \log P(x, y)$$

### 链式法则

$$H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$$

---

## 交叉熵

### 定义

**交叉熵**衡量真实分布为 $P$ 时，按模型分布 $Q$ 计分的期望负对数概率；使用以 2 为底的对数和理想编码时，可解释为期望编码长度：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

### 与熵的关系

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

其中 $D_{KL}(P \| Q)$ 是 KL 散度。

### 在 LLM 中的应用

在语言模型中：
- $P$：真实的下一个 token 的分布（one-hot 编码）
- $Q$：模型预测的下一个 token 的分布

**损失函数：**
$$L = H(P, Q) = -\sum_i P(i) \log Q(i)$$

对于 one-hot 编码，这简化为：
$$L = -\log Q(y)$$

其中 $y$ 是真实的 token。

---

## KL 散度

### 定义

**Kullback-Leibler 散度**衡量两个概率分布的差异：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

### 性质

| 性质 | 说明 |
|------|------|
| 非负性 | $D_{KL}(P \| Q) \geq 0$ |
| 非对称性 | 一般有 $D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ |
| 零点 | 当且仅当 $P=Q$（几乎处处）时为 0 |

### 直观理解

- $D_{KL}(P \| Q)$ 小：$Q$ 是 $P$ 的好近似
- $D_{KL}(P \| Q)$ 大：$Q$ 与 $P$ 差异大

### 在 LLM 中的应用

**微调（Fine-tuning）中的 KL 散度：**

在强化学习微调中，使用 KL 散度来防止模型偏离原始预训练分布太远：

$$L = L_{\text{task}} + \beta D_{\mathrm{KL}}(P_{\text{new}} \| P_{\text{reference}})$$

这里采用最小化损失的记号；若写成最大化奖励目标，KL 惩罚项的符号应相反。

---

## 互信息

### 定义

**互信息**衡量两个随机变量之间的**依赖程度**：

$$I(X; Y) = \sum_x \sum_y P(x, y) \log \frac{P(x, y)}{P(x)P(y)}$$

### 与熵的关系

$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

**直观理解：** 互信息是知道 $Y$ 后，$X$ 的不确定性减少的量。

### 性质

| 性质 | 说明 |
|------|------|
| 对称性 | $I(X; Y) = I(Y; X)$ |
| 非负性 | $I(X; Y) \geq 0$ |
| 独立性 | 当 $X$ 和 $Y$ 独立时，$I(X; Y) = 0$ |

### 在深度学习中的应用

**信息瓶颈（Information Bottleneck）：**

经典信息瓶颈目标在保留任务相关信息 $I(Z;Y)$ 与压缩输入信息 $I(Z;X)$ 之间做权衡。它是一种分析和建模原则，不表示普通神经网络训练会自动精确求解这两个互信息量。

---

## 困惑度

### 定义

**困惑度**是衡量语言模型性能的常用指标：

$$\text{Perplexity} = 2^{H(P, Q)} = 2^{-\frac{1}{N}\sum_{i=1}^{N} \log_2 Q(y_i)}$$

或者用自然对数：

$$\text{Perplexity} = e^{-\frac{1}{N}\sum_{i=1}^{N} \log Q(y_i)}$$

### 直观理解

困惑度可以粗略理解为模型在预测下一个 token 时的“有效分支因子”，而不是实际候选数量。PPL 为 10 并不表示模型每一步真的只比较 10 个 token。

### 与交叉熵的关系

$$\text{Perplexity} = e^{H(P, Q)}$$

在同一数据、tokenizer 和计分口径下，困惑度是交叉熵的单调变换，因此最小化交叉熵等价于最小化困惑度。

---

## 信息论中的不等式

### Jensen 不等式

对于凸函数 $f$：

$$f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$$

**应用：** 在 $P,Q$ 对同一有限支持均为正的简化条件下，用凸函数 $f(u)=-\log u$ 证明 KL 散度非负：

$$
D_{\mathrm{KL}}(P\|Q)
=\mathbb E_P\left[-\log\frac{Q(X)}{P(X)}\right]
\geq
-\log\mathbb E_P\left[\frac{Q(X)}{P(X)}\right]
=-\log\sum_xQ(x)=0.
$$

若存在 $P(x)>0$ 但 $Q(x)=0$，则 $D_{\mathrm{KL}}(P\|Q)=+\infty$，非负性仍成立。

### Gibbs 不等式

$$H(P, Q) \geq H(P)$$

**直观理解：** 在真实分布 $P$ 下进行平均，并采用同一对数底与理想编码口径时，使用 $Q$ 计分不会得到低于 $P$ 自身熵的交叉熵。

## 信息论在 LLM 中的应用

### 1. 训练目标

**最小化交叉熵：**
$$L = -\frac{1}{N}\sum_{i=1}^{N} \log P_{\theta}(y_i | x_i)$$

这等价于最大化模型对真实数据的似然。

### 2. 评估指标

**困惑度：**
$$\text{PPL} = e^{L}$$

在相同 tokenizer、数据和计分口径下，困惑度越低表示模型给测试 token 的平均概率越高；这不能推出模型在事实性、安全性或任务完成度上更好。

### 3. 微调中的正则化

**KL 散度正则化：**
$$L = L_{\text{task}} + \beta D_{KL}(P_{\text{new}} \| P_{\text{original}})$$

防止模型过度改变原始分布。

### 4. 对比学习

**对比目标：**
$$
L=-\log
\frac{\exp(s(x,x^+)/\tau)}
{\exp(s(x,x^+)/\tau)+\sum_{x^-}\exp(s(x,x^-)/\tau)}
$$

其中 $s$ 是相似度函数，$\tau$ 是温度参数。在特定采样与分布假设下，InfoNCE 可用于构造互信息下界；实际训练更直接优化的是匹配对相对候选集合的排序。

## 实践建议

### 监控训练

在训练 LLM 时，应该监控：

- [ ] **训练交叉熵**：观察平滑趋势、波动和异常尖峰，不要求每个 step 单调下降
- [ ] **验证集困惑度**：使用固定 tokenizer 和计分口径观察泛化趋势
- [ ] **梯度与数值状态**：监控梯度范数、NaN/Inf 和学习率变化

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 损失长期无改善 | 学习率、数据、Mask 或标签可能有问题 | 先检查小批过拟合、标签偏移和有效 token 比例，再调整学习率 |
| 损失出现 NaN/Inf | 数值范围、混合精度或异常 batch 可能有问题 | 定位首个异常 step，检查 logits、梯度范数和损失缩放 |
| 验证困惑度偏高 | 数据域不匹配、欠拟合或计分口径不一致 | 先固定 tokenizer 与数据，再比较训练/验证曲线和分组样本 |
| 训练改善而验证退化 | 可能过拟合或训练/验证分布不同 | 检查数据切分、重复样本、正则化和早停点 |

### 信息论的直觉

**记住这些关键概念：**

1. **熵**：不确定性的度量
2. **交叉熵**：编码成本
3. **KL 散度**：有方向的分布差异量，不是距离度量
4. **互信息**：变量之间的依赖
5. **困惑度**：平均负对数似然指数化后的语言建模指标
